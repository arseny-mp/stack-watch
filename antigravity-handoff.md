## 📋 1. Контекст и цель проекта
Проект **Stack Watch** — это автоматическая система мониторинга технологического стека (RSS, Github, YouTube), которая собирает обновления, фильтрует шум, переводит и структурирует дайджесты на русском языке с помощью Gemini API и доставляет их в Telegram-канал (через бота Hermes) и на Email.

**Главная задача текущей сессии:** Полностью перенести систему на автоматическую онлайн-схему в GitHub Actions (GHA) и отключить локальные запуски на macOS, которые часто сбоили из-за ограничений прав доступа (TCC/Permissions) к Google Drive и Keychain.

## 🛠️ 2. Что было сделано (Выполненные задачи)

### 1. Оптимизация скрипта курирования (`scripts/curate_findings.py`)
Чтобы избежать ошибок лимитов Gemini API (`429 Too Many Requests` и `503 Service Unavailable`) в облачной среде, логика работы куратора была полностью перестроена:
- **Разделение потоков (Step 1)**: Скрипт больше не отправляет ИИ пропущенные кандидаты (`screened_verdict == "skip"`). На вход Gemini идут только кандидаты со статусом `keep`.
- **Плоская схема**: Запрос Step 1 теперь возвращает легкую плоскую JSON-структуру с классификацией (slug, вердикт, tags, touches, action plan).
- **Программная сборка в Python**: Сборка итоговых файлов `summary.md`, `REPORT.md`, `log-additions.md` и `memory-index-additions.txt` теперь выполняется программно в коде Python на базе классификации, снижая трафик токенов к API на 85%.
- **Step 2 (Детализация)**: Подробные описания генерируются пакетами по 4 элемента с паузой в 15 секунд между запросами и автоматическим экспоненциальным откатом в случае ошибок.

### 2. Полное отключение локальных демонов `launchd`
- Локальные агенты macOS (`com.user.poll-feeds-research` и `com.user.bridge-antigravity-research`) были выгружены и отключены на хосте. Никаких конфликтующих локальных запусков больше не происходит.

### 3. Настройка репозитория и GitHub Actions
- Все локальные изменения закоммичены и отправлены в удаленный репозиторий `https://github.com/arseny-mp/stack-watch.git` (ветка `main`).
- В настройках репозитория GitHub Actions настроены следующие секреты:
  - `GEMINI_API_KEY`
  - `TELEGRAM_TOKEN_UPDATES`
  - `TELEGRAM_CHAT_ID`
  - `RCLONE_CONFIG` (конфиг Google Drive из `~/.config/rclone/rclone.conf` с данными сервисного аккаунта).

## 🎯 5. Инструкции для следующего чата / Дальнейшие шаги

Система находится в полностью рабочем автономном состоянии. При переходе в новый чат:
1. **Контроль за расписанием**: Конвейер воркфлоу GHA настроен на ежедневный запуск по расписанию (cron).
2. **Мониторинг Telegram**: Ежедневные новости теперь должны стабильно приходить в Telegram-канал напрямую из GitHub Actions.
3. **Локальный запуск (при необходимости отладки)**:
   Для ручной отладки локально используйте команду:
   ```bash
   export GEMINI_API_KEY=$(security find-generic-password -a user -s GEMINI_API_KEY -w) && python3 scripts/curate_findings.py
   ```
4. **Обновление рубрик/базы знаний**:
   При необходимости скорректировать вердикты ИИ обновляйте файлы `_rubric.md` и `learnings.md`, после чего делайте коммит и пуш в `main`. Конвейер GHA автоматически подтянет новые правила.
